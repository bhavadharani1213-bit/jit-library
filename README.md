# jit-library
ABSTRACT
The project proposes a Library Automation to automate book issue/return processes maintain an organized and searchable digital catalog, simplify library management through a centralized, cloud-backed system. Provide real-time updates on book availability, real-time notifications for overdue books, reservations, and visit logs.Generate reports for inventory, usage, and overdue items.
Manual library systems are time-consuming, prone to errors, and inefficient in managing large-scale data. The absence of a centralized system leads to misplaced records, delays, and poor user experience. Our system reduces manual workload and human error it also enhances user experience with faster book search and access, provides real-time inventory.

KEY FEATURES
•	Hybrid Mobile App using Flutter.
•	Role based registration page (Student / Staff / Admin).
•	Book search contains basic & advanced filters.
•	Notifications Alerts for Overdue books, Reservation & borrowing confirmations,Visit log entry/exit updates.
•	Only logged-in users (Student/Staff) can reserve books.
•	Admin can add/remove books, accept reservation / return requests.

 TECHNOLOGIES USED
1.	Frontend: Flutter (Dart)
2.	Backend: FirebaseFirestore (Database), Firebase Auth, Firebase Storage
3.	Other Libraries: url_launcher, google_fonts
4.	Voice search integration: Flutter plugin speech_to_text
5.	IDE: Android Studio / VS Code
6.	Platforms: Android, Web
7.	VersionControl: GitHub 


OUTCOMES AND IMPACT
 A fully functional, web and app-based library management system. Demonstrated ability to manage users, books, and transactions efficiently. Improved turnaround time for book issues and returns. Easy generation of reports and log.
